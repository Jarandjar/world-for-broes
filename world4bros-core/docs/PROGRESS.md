## Animation Acceptance Criteria
1. **Zero Foot Sliding**: No visible foot sliding at walk and run speeds; stride matching dynamically locks step frequency to ground movement velocity $\vec{v}$.
2. **Seamless Transitions**: Zero visual pops across clip crossfades, verified by automated `testPoseContinuity` delta thresholds.
3. **Strict CPU Budget**:
   - Laptop / Desktop: Entire crowd animation system stays under **$\le 2$ ms per frame** with 150 active zombies.
   - Mobile Phone: Crowd animation stays under **$\le 4$ ms per frame** with 60 active zombies.
4. **Single-Source State Mapping**: Every entity maps game state to animation state through a single deterministic function (`entity.updateAnimationState()`), with zero scattered, ad-hoc `play()` calls across gameplay logic.
5. **Frame-Accurate Combat Synchronization**: Damage, audio impacts, and screen punch during attack clips are dispatched strictly upon the `hit_frame` animation event.
